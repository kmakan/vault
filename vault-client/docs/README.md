### Быстрый старт

```bash
# 1. Сборка
cd vault-client
cargo build --release

# 2. Запуск
./target/release/vault-client --cli

# 3. Подключение
/connect user@gmail.com abcdefghijklmnop

# 4. Ключи
/keygen

# 5. Приглашение
/invite alice@example.com

# 6. Чат
/chat alice@example.com
```

## Безопасность

### Принципы

1. **E2E шифрование** — сообщения шифруются на устройстве отправителя
2. **Forward Secrecy** — компрометация ключа не влияет на прошлое
3. **Верификация ключей** — проверка личности контакта
4. **Контроль контактов** — только согласные пользователи

### Алгоритмы

| Алгоритм | Назначение |
|----------|------------|
| X25519 | Обмен ключами |
| HKDF | Вывод ключей |
| XChaCha20-Poly1305 | Шифрование |
| Poly1305 | Аутентификация |
