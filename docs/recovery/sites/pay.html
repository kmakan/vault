Оплата Vault Pro

Покупка оформляется на этом сайте, а подписка включается в приложении сама — сразу после оплаты. Цены считает сервер; оплата ведёт на защищённую платёжную страницу ЮKassa (карта, СБП, SberPay, ЮMoney).

Шаг 1 · Код оплаты

Введите код оплаты из приложения

Откройте Vault → «Настройки» → «Приватность» → «Тариф Pro» → нажмите «Копировать код». Это отпечаток вашего аккаунта, а не пароль: по нему нельзя войти в аккаунт — только выдать уже оплаченную подписку.

Приложения ещё нет? Скачать Vault для Android (arm64, бесплатно, установка из этого источника). В сборке с сайта (0.1.294) Pro покупается прямо в приложении — кнопками периода. Код ниже нужен для сборки из магазина: там кнопок покупки нет (магазин не разрешает платёж в обход своей кассы), поэтому оплата — здесь.

Шаг 2 · Срок

Выберите срок

Витрина цен недоступна — обновите страницу. Цена всё равно считается сервером, страница её не придумывает.

Шаг 3 · Способ оплаты

Оплата криптовалютой подключается на этом канале отдельно — если способ не виден, доступна карта.

После оплаты вернитесь в приложение: оно получает подписку с сервера само, ничего вводить повторно не нужно. Вопросы и чеки — vault-msg@ya.ru. Описание тарифов — Тарифы.
