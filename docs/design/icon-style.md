## Целевой стиль (гайд)

1. **Геометрия**: stroke-иконки в 24px viewBox (lucide-классика), stroke-width
   **2**, round caps/joins, fill=none. Один источник путей — `src/icons.js`
   (именованные path-строки) + обёртка `<Icon name="..." :size="..">`, чтобы
   не дублировать `<svg><defs><linearGradient>` в каждом месте.
2. **Цвета**:
   - **Акцентные** (создать группу, логотип, главные действия шапки):
     градиент `#818cf8 → #c084fc` (indigo→violet) на глифе + мягкое свечение
     (drop-shadow 4px rgba(139,92,246,.5)) — узнаваемая фишка Vault.
   - **Нейтральные** (hover-действия сообщений, навигация): `currentColor`
     (muted, светлеет на hover) — как сейчас у reply/copy/edit/delete.
3. **Размерная сетка**:
   - Кнопки шапки/главные действия: **18–20px**;
   - Мелкие индикаторы (счётчик участников, секции сайдбара): **14–16px**;
   - Hover-кнопки сообщений: **14–16px** (ужимаются, чтобы не вылезать за
     пузырь);
   - Плашки/кнопки с текстом (скачать, экспорт): иконка 14–16px + текст.
4. **Что остаётся эмодзи** (по решению 17–19.08): только статусные/декоративные
   маркеры (🔒 плашка пустого чата, ✅, badge участника), реакции-контент
   (эмодзи реакций), и ничего функционального.
5. Поведение: hover — лёгкий scale(1.08–1.1) + усиление свечения у акцентных
   (паттерн `.group-create-icon` уже есть), смена currentColor у нейтральных.
