# Vault — руководство пользователя

Vault — мессенджер со сквозным шифрованием (E2E). Транспорт — обычная
электронная почта: у Vault нет своих серверов с вашими данными, переписка
хранится только на ваших устройствах и в ваших почтовых ящиках (в
зашифрованном виде). Криптография — постквантовый гибрид ML-KEM-768 +
X25519 (плюс подпись Ed25519 и симметричное XChaCha20-Poly1305).

- Сайт: https://vault-msg.ru (RU) / https://vault-msg.tech (EN)
- Репозиторий: https://github.com/kmakan/vault
- Версия руководства: 0.1.155

## 1. Установка

- **Android**: APK с сайта (раздел «Скачать») или из GitHub Releases.
  Android 9+, архитектура arm64. Установите файл, разрешив «из
  неизвестных источников» для браузера.
- **Linux**: tar.gz (распаковать, запустить `vault-desktop`) или deb
  (`sudo apt install ./Vault_...deb`).
- Обновления: Настройки → Помощь → «Проверить обновление» (сравнивает
  версию с сайтом и даёт ссылку на свежий файл).

## 2. Вход

1. Запустите Vault.
2. Введите email и **пароль приложения** (не основной пароль от почты!).
   - Gmail: https://myaccount.google.com/apppasswords
   - Yandex / Mail.ru / Outlook: раздел «Пароли приложений» в настройках.
3. Галочка «Запомнить на этом устройстве» → «Войти».

Пароль вводится один раз: он сохраняется на устройстве в зашифрованном
виде (ключ шифрования привязан к этому устройству). «Выйти» стирает
сохранённый пароль с устройства.

**Совет**: используйте для Vault отдельный чистый почтовый ящик. Ящик,
заваленный обычной почтой и рассылками, замедляет открытие чатов.

## 3. Профиль и ID

- Настройки → Профиль: имя, аватар, статус-био — рассылаются контактам
  автоматически при сохранении (и при смене почты).
- **ID (отпечаток ключа)** — виден в профиле и QR. Он не меняется при
  смене почты, по нему вас находят в группах после смены адреса.
- Смена почты: Настройки → «Сменить почту» — контакты, группы и ключи
  сохраняются (участники групп узнают ваш новый адрес по отпечатку).

## 4. Добавление контакта (обмен ключами)

### Способ A — Приглашение по ID (через email)
1. 🔗 «Добавить контакт» → введите ID собеседника → «Отправить запрос».
2. Собеседник получит приглашение с кнопками «Принять/Отклонить».
   После принятия ключи обменяются автоматически.

### Способ B — QR-код (лично)
Раскройте «Показать QR-код» — собеседник сканирует устройством с Vault.

### Способ C — Ключ через любой канал
«Скопировать ключ» → передайте любым способом → собеседник вставляет его
в «Добавить ключ» и указывает ваш email.

> Публичный ключ можно передавать открыто — он не позволяет читать
> переписку, только шифровать для вас.

## 5. Чаты и сообщения

- **Отправка**: текст → Enter. Сообщение уходит письмом без темы;
  провайдер видит только факт письма. ✓ — отправлено, ✓✓ —
  доставлено/прочитано.
- **Файлы и фото**: скрепка → до 25 МБ (лимит зависит от провайдера).
  Вложения шифруются на устройстве.
- **Голосовые**: удерживайте микрофон — запись отправляется как
  зашифрованное аудио.
- **Гео**: булавка → координаты карте (у получателя — ссылка на карту).
- **Голосования**: карточка-опрос → участники голосуют в один тап,
  результат агрегируется у всех.
- **Избранное**: долгое нажатие на сообщение → «В избранное»; звезда в
  шапке чата показывает только помеченные.
- **Исчезающие сообщения**: таймер (30 с … 7 дней) на чат — новые
  сообщения удаляются после прочтения.
- **Реакции**: эмодзи-реакция на любое сообщение.
- **Пересылка**: контекстное меню сообщения → «Переслать».
- **Удалить у меня**: контекстное меню — сообщение исчезает только у вас
  (у собеседника остаётся).

## 6. Группы

- Создание: «+» → название → участники из контактов.
- Приглашение приходит письмом с кнопкой согласия.
- Роли: создатель/админ может добавлять участников.
- Ключ группы шифруется для каждого участника отдельно.
- Смена почты участником не выпадает из группы (матчинг по отпечатку).

## 7. Звонки

Аудио-звонки E2E (Opus + SRTP, гибридный постквантовый ключ сессии).

- Кнопка трубки в шапке чата → вызов; сигнал вызова идёт
  (как и всё) почтой/релеем, соединение P2P (WebRTC).
- «Соединение…» несколько секунд после принятия — норма (рукопожатие
  через почтовый транспорт).
- Звонки работают и в экономном режиме.

## 8. Релей (ускоренная доставка)

Релей — опциональный ускоритель: дублирует зашифрованный конверт поверх
почты, доставляя его за ~1 секунду. **Почта остаётся каналом-гарантом:
релей ничего не меняет в безопасности, только скорость.**

- Настройки → Приватность → «Ускоренная доставка через релей» →
  «Подключить наш релей» — бесплатный токен на 30 дней (продлевается
  той же кнопкой; привязан к вашему устройству/ключу).
- Пуш-уведомления при закрытом приложении: установите ntfy-клиент
  (F-Droid/Google Play) и откройте ntfy-ссылку из настроек — телефон
  будет просыпаться от системного пуша.
- **Лимит бесплатного релея**: 100 конвертов в сутки (сброс 00:00 UTC).
  При исчерпании доставка тихо идёт почтой, ничего не теряется; конверт
  в шапке чата показывает режим «почта». Безлимит — по промо-ключу
  (тестеры/премиум).
- Можно указать **свой релей** (любой совместимый сервер) — Настройки →
  Приватность → Расширенные. Наш релей видит только зашифрованные байты
  и одноразовые токены, без адресов и содержимого.

## 9. Экономный режим (батарея)

Настройки → Приватность → «Экономный режим»:

- **ВКЛ**: постоянная служба гасится (иконка из шторки исчезает), приём —
  через релей + системные пуши ntfy. Максимальная экономия батареи.
- **ВЫКЛ (классика)**: постоянная служба с иконкой — мгновенный приём
  и звонки, чуть больше батареи.
- **Устойчивость**: если релей недоступен (блокировка/авария), в эко-режиме
  приложение само поднимает службу и переключается на почту — сообщения
  и звонки продолжают приходить, работа не отличается от обычной
  (разница — иконка в шторке и скорость доставки). При восстановлении
  релея — тихий возврат в экономный режим.

## 10. Приватность и защита

- **Замок приложения**: PIN-код при входе + разблокировка отпечатком
  (Android, если сканер поддерживается). Настройки → Приватность.
- **Аварийная защита (duress)**: три кода — обычный вход, duress-код
  (вход «как обычно» + тихое SOS-письмо доверенным контактам с
  координатами, если включено) и panic-код (мгновенное стирание всех
  данных приложения на устройстве).
- **SOS-рассылка**: выбор получателей из контактов, гео-тумблер.
- **Бэкапы**: Настройки → экспорт/импорт ключей (файл с приватным
  ключом — храните надёжно; при переносе на новое устройство ключи
  восстанавливают все чаты).
- **Что видит провайдер**: факт писем между адресами и время. Темы
  пустые, содержимое зашифровано и аутентифицировано.

## 11. Почтовые папки

Vault читает INBOX и Спам (Gmail кладёт шифрописьма в Spam) и папку
«Письма себе» (Sent-копии). История чатов хранится локально (SQLite),
поэтому удаление писем из ящика не стирает переписку в приложении.

## 12. Частые вопросы

**Приглашение не видно?** Приглашение — обычное письмо: проверьте папку
«Спам» и что ящик собеседника совпадает с указанным.

**Можно ли с телефона?** Да — Android-версия это то же приложение
(Tauri 2). iOS — в планах.

**Забыл PIN замка?** Замок снимается переустановкой приложения с
последующим входом (данные чатов сохраняются в ящике; локальные метки —
избранное, настройки — сбросятся). Panic-код стирает всё мгновенно —
не забывайте его.

**Как перенести на новый телефон?** Настройки → «Экспорт ключей» →
на новом устройстве «Импорт ключей» → вход тем же ящиком.

**Что если релей закроют?** Ничего не изменится: доставка мгновенно
перейдёт на почту (клиент делает это автоматически и показывает конверт
в шапке). Vault работает и вовсе без релея.

## 13. Устранение неполадок

- **Пустой чат при открытии** — первый фетч писем; подождите или
  нажмите «Перечитать группу» (стрелки в шапке группового чата).
- **Сообщения приходят с задержкой ~30 с** — это почтовый поллинг;
  включите релей для мгновенной доставки.
- **Звонок не соединяется** — проверьте интернет; рукопожатие идёт
  почтой и может занять до минуты при медленном провайдере.
- **Кнопка «Обновить» не открывает браузер** — на Android используйте
  встроенную проверку обновлений, ссылка копируется в буфер.
