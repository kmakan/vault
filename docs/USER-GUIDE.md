# Vault — инструкция пользователя

Vault — мессенджер со сквозным шифрованием (E2E). Транспорт — обычная
электронная почта: у Vault нет своих серверов, переписка хранится только
на ваших устройствах и в ваших почтовых ящиках (в зашифрованном виде).

## 1. Вход

1. Запустите Vault.
2. Введите email и **пароль приложения** (не основной пароль от почты!).
   - Gmail: https://myaccount.google.com/apppasswords
   - Yandex / Mail.ru / Outlook: раздел «Пароли приложений» в настройках.
3. Оставьте галочку «Запомнить на этом устройстве» и нажмите «Войти».

Пароль вводится **один раз**: он сохраняется на устройстве в зашифрованном
виде (ключ шифрования привязан к этому устройству), и при следующих
запусках Vault входит автоматически. Выход («Выйти») стирает сохранённый
пароль с устройства.

## 2. Добавление контакта (обмен ключами)

Чтобы начать защищённый чат, нужно обменяться публичными ключами.
Три способа — выберите любой:

### Способ A — Приглашение по ID (через email)
1. Нажмите 🔗 «Добавить контакт».
2. Введите ID собеседника (его email) → «Отправить запрос».
3. Собеседник получит приглашение с кнопками «Принять/Отклонить».
   После принятия контакт появится у обоих — ключи обменялись автоматически,
   ничего вводить не нужно.

### Способ B — QR-код (лично или с другого устройства)
1. В панели «Добавить контакт» раскройте «Показать QR-код».
2. Собеседник сканирует код устройством с Vault — ключ и email добавятся
   автоматически.

### Способ C — Ключ через любой канал (мессенджер, SMS, лично)
Если email-приглашение неудобно (например, контакт не проверяет эту почту):
1. В панели «Добавить контакт» раскройте «Скопировать ключ».
2. Передайте ключ собеседнику любым способом.
3. Собеседник вставляет его в поле «Добавить ключ» (шаг 3 панели) —
   и указывает ваш email. Готово.

> Публичный ключ можно передавать открыто — он не позволяет читать
> переписку, только шифровать для вас.

## 3. Скорость открытия чатов — важно

Vault читает переписку из вашего почтового ящика. Поэтому:

- **Используйте для Vault отдельный почтовый ящик.** Если ящик одновременно
  используется как обычная почта (сотни/тысячи писем, рассылки, спам),
  Vault перебирает их при каждом подключении — открытие чатов и поиск
  новых сообщений становятся заметно медленнее. Чистый ящик «только для
  Vault» = быстрая работа.
- **Первое открытие чата** после входа может занять несколько секунд:
  Vault скачивает и расшифровывает письма.
- **Повторные открытия — мгновенные**: расшифрованные сообщения кэшируются
  локально на устройстве и не скачиваются заново.
- Новые сообщения появляются автоматически (проверка каждые 30 секунд).

## 4. Отправка сообщений

1. Выберите контакт в списке слева.
2. Введите текст → Enter.
3. Сообщение шифруется на устройстве и уходит письмом без темы
   (провайдер почты видит только факт письма, не содержимое).
4. ✓ — отправлено, ✓✓ — доставлено/прочитано.

## 5. Группы

- Создание: «+» в списке чатов → название → участники из контактов.
- Приглашение в группу приходит письмом с кнопкой согласия.
- Ключ группы шифруется для каждого участника отдельно.

## 6. Безопасность

- Приватный ключ хранится только на вашем устройстве (`~/.vault/keys/`).
- Пароль от почты сохраняется на устройстве в зашифрованном виде
  (`~/.vault/credentials/`, ключ шифрования — только на этом устройстве).
  Вход после перезапуска автоматический; «Выйти» стирает пароль.
- Удаление контакта удаляет его ключ; старые сообщения остаются у вас.

## 7. Частые вопросы

**Почему собеседник не видит моё приглашение?**
Приглашение — обычное письмо. Проверьте, что собеседник смотрит тот ящик,
на который отправлено приглашение (и папку «Спам» — Gmail иногда кладёт
туда шифрованные письма).

**Можно ли пользоваться Vault с телефона?**
Да, Android-версия в разработке (vault-android, тот же Tauri-стек).

**Что видит почтовый провайдер?**
Только факт писем между вами и собеседником (адреса, время). Темы писем
пустые, содержимое зашифровано и аутентифицировано (XChaCha20-Poly1305).
