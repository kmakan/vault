# Code of Conduct

## Our commitment

Vault is built by and for people who care about private communication.
We want participation here to be useful and safe for everyone, regardless of
experience level, language, background, or role.

## Expected behavior

- Be respectful: critique code and ideas, not people.
- Assume good faith: most contributions come from a genuine wish to improve
  the project; ask questions before accusing.
- Keep discussions technical: issue threads, PR reviews and chats are for
  improving Vault.
- Give credit: acknowledge prior art and other people's work in patches
  and discussions.
- Report problems responsibly: security issues go to the private channel in
  [SECURITY.md](SECURITY.md), not to public issues.

## Unacceptable behavior

- Harassment, personal attacks, insults, discriminatory remarks.
- Spam, advertising, and off-topic promotion in issues or pull requests.
- Publishing other people's personal data (doxxing), including in bug reports
  and logs — sanitize logs before attaching them.
- Using the project's infrastructure (issues, discussions) to attack third
  parties.

## Enforcement

Maintainers may edit, remove, or reject comments, issues, and pull requests
that violate this document, and may temporarily or permanently ban
contributors who repeatedly violate it. Enforcement decisions are made by
project maintainers and can be discussed privately with them.

If something on this repository bothers you, write to
[kmakan@zoho.com](mailto:kmakan@zoho.com) — we read everything.

## Scope

This code of conduct applies to all project spaces: issues, pull requests,
discussions, releases, and any public representation of the project.
