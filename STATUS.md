# 📋 Whisper — Заметки проекта

## Название
- **Рабочее**: MailCipher (внутреннее)
- **Продвижение**: **Whisper** (основное)
- **Запасное**: Vault

## Стек технологий
- **Backend**: Rust (Axum/Actix-web) + SQLx + PostgreSQL
- **Desktop**: Tauri 2.0 (Rust + Svelte)
- **Terminal**: Rust (ratatui)
- **Android**: Kotlin + Jetpack Compose
- **БД**: PostgreSQL (прод) / SQLite (dev)

## Причины выбора Rust
- **Безопасность памяти** — нет буферных переполнений, утечек
- **Нет GC** — стабильная работа без пауз
- **Криптография** — ring, sodiumoxide, rust-crypto
- **Производительность** — как C, но безопаснее

## Порядок разработки
1. **Backend** — базовая структура (Rust)
2. **Клиент** — чаты и групповые чаты (Rust terminal)
3. **Шифрование** — после стабильности клиента
4. **Передача ключей** — ручная загрузка (флешка/файл)
5. **Генератор ключей** — встроенный в клиент

## Управление ключами
- **Подход**: ручная загрузка ключей (флешка/файл)
- **Два ключа**: один для шифрования, другой для расшифрования
- **Генератор ключей**: встроенный в клиент
- **Передача ключей**: на усмотрение пользователя (не наша задача)
- **Алгоритмы**: Alpha (колонная замена) или другие на выбор

## Ключевые решения
1. **Email как транспорт** — минимизация внешней блокировки
2. **Ключи в клиенте** — почтовый клиент видит "мусор", наш — чат
3. **Маркировка сообщений** — отличаем наши от обычных email
4. **Zero-knowledge** — сервер не видит сообщения
