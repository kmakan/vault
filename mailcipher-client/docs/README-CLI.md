# Vault CLI — Руководство пользователя

E2E зашифрованный мессенджер на базе email.

## Быстрый старт

```bash
# 1. Сборка
cd mailcipher-client
cargo build --release

# 2. Запуск
./target/release/mailcipher-client --cli
```

## Установка

### Из исходников

```bash
# Клонируем репозиторий
git clone https://github.com/user/vault.git
cd vault/mailcipher-client

# Сборка (требуется Rust 1.70+)
cargo build --release

# Бинарник
./target/release/mailcipher-client
```

### Требования

- Rust 1.70 или новее
- Аккаунт email (Gmail, Outlook, Yandex, Mail.ru)
- Пароль приложения (для IMAP/SMTP)

## Получение пароля приложения

### Gmail

1. Перейдите в [Настройки Google](https://myaccount.google.com/security)
2. Включите **Двухфакторную аутентификацию**
3. Перейдите в **Пароли приложений**
4. Создайте пароль для "Vault"
5. Скопируйте 16-значный пароль

### Outlook / Hotmail

1. Перейдите в [Аккаунт Microsoft](https://account.live.com/proofs/AppPasswords)
2. Создайте пароль приложения
3. Скопируйте пароль

### Yandex

1. Перейдите в [Настройки](https://passport.yandex.ru/profile/security/app-passwords)
2. Создайте пароль для "Vault"
3. Скопируйте пароль

### Mail.ru

1. Перейдите в [Настройки](https://account.mail.ru/u#security)
2. Создайте пароль приложения
3. Скопируйте пароль

## Подключение аккаунта

```bash
# Подключение к Gmail
/connect user@gmail.com abcdefghijklmnop

# Подключение к Outlook
/connect user@outlook.com abcdefghijklmnop outlook.office365.com

# Подключение к Yandex
/connect user@yandex.ru abcdefghijklmnop imap.yandex.com
```

### Автоматическое определение сервера

| Домен | IMAP сервер | SMTP сервер |
|-------|-------------|-------------|
| gmail.com | imap.gmail.com | smtp.gmail.com |
| outlook.com | outlook.office365.com | smtp.office365.com |
| yandex.ru | imap.yandex.com | smtp.yandex.com |
| mail.ru | imap.mail.ru | smtp.mail.ru |

## Генерация ключей

```bash
# Генерация новой пары ключей
/keygen

# Просмотр текущих ключей
/keys

# Общий вид:
# Key status:
#   ✓ Keys loaded
#   Fingerprint: a1b2:c3d4:e5f6:...
#   Public key: 04a1b2c3d4...
```

### Что происходит при генерации

1. Создается приватный ключ (X25519, 32 байта)
2. Создается публичный ключ (64 байта)
3. Вычисляется fingerprint (отпечаток)
4. Ключи сохраняются локально

## Добавление контактов

### Через invite-ссылку

```bash
# Генерация invite-ссылки для контакта
/invite alice@example.com

# Вывод:
# Invite link: https://vault.chat/invite/abc123...
# QR-код: (отображается в терминале)
# Срок действия: 24 часа
```

### Принятие приглашения

```bash
# Принять приглашение по ссылке
/accept https://vault.chat/invite/abc123...

# Или по Vault ID
/accept alice@example.com
```

### Просмотр контактов

```bash
# Список контактов
/contacts

# Информация о контакте
/whois alice@example.com
```

## Переписка

### Начало чата

```bash
# Начать чат с контактом
/chat alice@example.com

# Вывод:
# Entered chat with alice@example.com
# Type messages to send. /leave to exit chat.
```

### Отправка сообщений

```bash
# В режиме чата просто печатайте текст
Привет! Как дела?

# Или через команду
/send Привет! Как дела?
```

### Ответ на сообщение

```bash
# Ответить на конкретное сообщение
/reply msg-123 Спасибо за информацию!
```

### Просмотр треда

```bash
# Показать цепочку сообщений
/thread Meeting notes
```

### Выход из чата

```bash
/leave
```

## Шифрование вручную

### Шифрование текста

```bash
# Зашифровать текст
/encrypt Мой секретный текст

# Вывод:
# Encrypted: 04a1b2c3d4e5f6...
```

### Дешифрование текста

```bash
# Расшифровать текст
/decrypt 04a1b2c3d4e5f6...

# Вывод:
# Decrypted: Мой секретный текст
```

## Работа с файлами

### Прикрепление файла

```bash

# Файл будет зашифрован перед отправкой
```

```bash
# Отправить зашифрованный файл

```

|-----------|---------------------|

## Статусы сообщений

| Статус | Иконка | Значение |
|--------|--------|----------|
| Отправлено | ✓ | SMTP принял сообщение |
| Доставлено | ✓✓ | Получатель получил письмо |
| Прочитано | ✓✓ (синий) | Получатель расшифровал |

## Редактирование сообщений

### Редактировать сообщение
```bash
/edit <message_id> <новый текст>
```

### Просмотр истории редактирования
```bash
/editinfo <message_id>
```

### Отменить последнее редактирование
```bash
/editundo <message_id>
```

**Ограничения:**
- Максимум 10 редактирований на сообщение
- Окно редактирования: 1 час
- Только автор может редактировать

## Медиа-превью (Kitty Graphics)

### Просмотр превью в терминале
```bash
/thumb <путь_к_файлу> [s|m|l]
/th <путь_к_файлу> [s|m|l]
```

**Размеры:**
- `s` — small (64×64)
- `m` — medium (128×128)
- `l` — large (256×256)

### Информация о медиа-файле
```bash
/thumbinfo <путь_к_файлу>
/ti <путь_к_файлу>
```

**Поддерживаемые протоколы:**
- Kitty (авто-определение)
- iTerm2
- Sixel (заглушка)
- ASCII art fallback

## Безопасность

### Верификация ключей

```bash
# Сравните fingerprint с контактом
/whois alice@example.com

# Если fingerprint совпадает → ключ верифицирован
```

### Хранение ключей

- Приватный ключ хранится локально
- Никогда не отправляется
- Зашифрован мастер-паролем

### Forward Secrecy

- Каждое сообщение использует уникальный ключ
- Компрометация одного ключа не влияет на другие

## Решение проблем

### Ошибка подключения

```
Error: Connection failed
```

**Решение:**
1. Проверьте email и пароль
2. Убедитесь, что IMAP включен в настройках почты
3. Проверьте настройки безопасности (разрешены приложения)

### Ошибка шифрования

```
Error: Could not decrypt
```

**Решение:**
1. Убедитесь, что у вас правильный ключ
2. Проверьте, что контакт верифицирован
3. Попросите отправителя повторить отправку

### Ошибка отправки

```
Error: Send failed
```

**Решение:**
1. Проверьте подключение к интернету
2. Убедитесь, что SMTP сервер доступен
3. Проверьте лимиты провайдера

## Примеры

### Полный цикл переписки

```bash
# 1. Подключаем аккаунт
/connect user@gmail.com abcdefghijklmnop

# 2. Генерируем ключи
/keygen

# 3. Добавляем контакт
/invite alice@example.com

# (alice принимает приглашение)

# 4. Начинаем чат
/chat alice@example.com

# 5. Отправляем сообщение
Привет! Это тестовое сообщение.

# 6. Проверяем статус
# ✓ → ✓✓ → ✓✓ (синий)

# 7. Выходим из чата
/leave
```

### Групповой чат

```bash
# 1. Создаем группу
/group create "Project Team"

# 2. Добавляем участников
/group add alice@example.com
/group add bob@example.com

# 3. Отправляем сообщение в группу
/group send "Project Team" Всем привет!
```
