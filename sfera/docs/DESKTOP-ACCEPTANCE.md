# Sfera Desktop — чек-лист приёмки

Ручная проверка перед показом и релизом. Автоматические гейты
(`test:contract`, `cargo test --workspace`) обязательны, но не заменяют этот
список: они не видят окно, шрифты и раскладку.

## Запуск

```bash
cd ~/whisper/sfera
npm run tauri dev
```

Приложение берёт ключ из `~/.vault/keys` (или `VAULT_KEYS_DIR`). Если ключа
нет — окно не откроется и будет понятная ошибка; это ожидаемое поведение.

## Основной проход

- [ ] Окно открывается, заголовок **Sfera**, без белого экрана и без крэша.
- [ ] Пять вкладок: Лента, Контакты, Создать, Хранилище, Профиль.
- [ ] Стартовая вкладка — «Лента»; переключение не теряет состояние.
- [ ] «Лента»: пустое состояние «Пока нет постов от ваших контактов».
- [ ] «Контакты»: пустое состояние «Контактов пока нет» (пока нет данных).
- [ ] «Создать»: поле ввода, адресат «Сначала создайте сферу в контактах»,
      кнопка «Опубликовать» недоступна.
- [ ] «Хранилище»: тип `Local`, квота «Без ограничения», бейдж `Range`.
- [ ] «Профиль»: «Аккаунт: Не связан», отпечаток **ключа устройства**,
      подсказка про QR. Отпечаток не выдаётся за аккаунт мессенджера.

## Клавиатура

- [ ] `Ctrl+1…5` переключают вкладки в том же порядке, что в навигации.
- [ ] Ввод в поле поста не перехватывается этими сочетаниями.

## Язык и тема

<!-- hygiene:cjk-begin -->
- [ ] Русский → English → 中文: меняются все подписи, включая вкладки.
<!-- hygiene:cjk-end -->
- [ ] После смены языка нет «сырых» ключей вида `nav_feed`.
- [ ] Темы dark / light / amber: меняются фон, текст и акцент.
- [ ] Нет невалидных CSS-переменных (фон кнопки не становится прозрачным).

## Раскладка

- [ ] При ширине окна ≤ 720 px навигация уходит вниз, контент не перекрыт.
- [ ] Длинный отпечаток и длинный текст переносятся, а не вылезают за карточку.
- [ ] При 360×560 px ничего не обрезано и не наезжает.

## Устойчивость

- [ ] Закрыть и открыть приложение: отпечаток тот же, ошибок нет.
- [ ] В консоли нет ошибок `Tauri runtime is not available` и `invoke`.
- [ ] Нет паники Rust в терминале.

## Известные пробелы MVP (не дефекты приёмки)

- Аккаунт не связан: устройство имеет свой ключ, сертификат аккаунта ещё не
  выдаётся (протокол §8). Поэтому доставка и контакты не работают.

- Создание сфер и приглашений из UI ещё не подключено — «Создать» честно
  показывает отсутствие адресата.
- Кнопка мессенджера в профиле появится вместе с OS-адаптером `vault://open`.
- Медиа в хранилище пока не загружается: экран показывает возможности
  провайдера, а не файлы.
