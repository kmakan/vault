# Vault v0.1.171 — Release Notes

**Дата**: 16 сентября 2026
**Платформы**: Linux (tar.gz), Android (APK), CLI

## Что нового (с 0.1.167)

### Каналы (экспериментально)
- Широковещательные каналы: автор публикует текстовые посты, подписчики читают
- Ссылка подписки `vault://join-channel…` — ключ канала внутри ссылки,
  подписка мгновенна и без подтверждения автору
- Приватность в обе стороны: подписчики не видят друг друга, релей видит только
  шифрованный конверт (fan-out из одной копии)
- Мeta-конверты: имя/описание/аватар канала обновляются вещанием, сайдбар
  подписчиков подстраивается сам
- Доставка: релей (мгновенно) + почтовый дубль для подписчиков, известных автору
- UI: секция «Каналы» в сайдбаре, непрочитанные, mute, переименование/удаление,
  composer только у автора

### Боты (экспериментально)
- `vault --listen`: headless-режим CLI-клиента — входящие/исходящие по
  NDJSON-контракту поверх того же E2E wire-формата
- Пример моста к любому OpenAI-совместимому ассистенту в `vault-bot/`
- Бот = обычный Vault-аккаунт: тот же QR-контакт, тот же транспорт, без
  привилегий на сервере

### Интерфейс
- Липкие вкладки-якоря «Чаты / Группы / Каналы» в списке: счётчики, индикатор
  непрочитанного, мгновенный переход к секции, скролл-спай
- Компактная шапка сайдбара: панель «Каналы» вместо россыпи кнопок (фикс
  переполнения на узких окнах)

### Релей и транспорт
- Канальные токены (read/write) детерминированы из broadcast-ключа; метрики
  `channel_pub`, `poll_hits`; курсор `since` для fan-out; честный premium-gate
  (канальный sentinel не обходит суточный лимит)
- `peek` без drain для каналов: каждый подписчик получает каждый пост

### Фиксы
- listen: скан INBOX+Junk+ToMyself; полный фетч тела для PQ-конвертов >1 КБ;
  durable-дедуп (без повторных ответов после рестарта); логи в stderr
- vaultbot: построчный stdin (pipe-буферизация не задерживает ответы)
- folders: флаг mute для каналов не теряется
- прочее: whitespace-чистка, синхронизация версий артефактов

## Что такое Vault

Приватный мессенджер, работающий через обычную почту. Без своих серверов.
Ключи и история — только на устройстве. Релей — опциональный ускоритель,
не видит содержимого (E2E) и не требуется для работы.
