# Vault v0.1.157 — Release Notes

**Дата**: 10 сентября 2026
**Платформы**: Linux (tar.gz), Android (APK), CLI

## Что нового (с 0.1.140)

### Релей (vault-msg.ru/relay) — мгновенная доставка
- Дублирующий ускоритель поверх почты: доставка 1–2 с вместо 30–60 с
- Автообмен токенами в конвертах — пользователю не нужно ничего вводить
- ntfy-пуши при звонке (wake только для call_request — без лишних уведомлений)
- Суточный лимит 100 конвертов (тихий фолбэк на почту, ничего не теряется)
- Анти-шаринг токена (привязка к отпечатку ключа)
- Эко-режим: минимизирует батарею, авто-автономный режим при блокировке релея

### Звонки — стабильность (0.1.157)
- **Фикс**: пустой UI при входящем звонке — глобальный error-handler Vue:
  ошибка рендера больше не убивает всё приложение, логируется со стеком
- **Фикс**: шумный underrun-шторм cpal+PipeWire (48k+ строк в логе за звонок) —
  ошибки потока ограничены по частоте, одноразовые звуки останавливаются сами
- **Фикс**: вызов несуществующей команды call_report_state на десктопе

### Прочее
- Метрики релея, health-чек, авто-фолбэк между релеями
- Read receipts, статусы доставки, индикатор канала (релей/почта)

## Что такое Vault

Приватный мессенджер, работающий через обычную почту. Без своих серверов.
Ключи и история — только на устройстве. Релей — опциональный ускоритель,
не видит содержимого (E2E) и не требуется для работы.

## Шифрование

- **Гибрид ML-KEM-768 + X25519** (PQ1) — постквантовый обмен ключами
- **XChaCha20-Poly1305** — сообщения, вложения, локальное хранилище
- Legacy-путь X25519 для контактов без PQ-ключей
- Обмен ключами: QR-код, отпечаток (fingerprint) для верификации

## Мессенджер

- 1-на-1 и групповые чаты (роли, инвайты по QR/ссылке)
- Редактирование, удаление, закрепление, реакции, ответы, пересылка
- Избранное, исчезающие сообщения (TTL), папки, заметки
- Вложения, аудиосообщения, экспорт, поиск (FTS5)
- Мультиаккаунтность, смена почты без потери контактов

## Звонки

- Голосовые 1-на-1: Opus 48 кГц, AEAD + DTLS-SRTP
- P2P, сигнализация E2E-конвертами (почта + релей)
- Рингтоны, нативные кнопки ответа, биометрия (Android)

## Безопасность

- Duress-пароль / panic-код, SOS-рассылка с геолокацией
- Стелс-письма (пустые темы, нет маркеров)
- Android: allowBackup=false; никакой телеметрии

## Клиенты

- **Desktop** — Tauri 2 (Rust + Vue 3)
- **Android** — Tauri 2, APK (подписан release-ключом)
- **CLI** — Rust REPL, паритет wire-формата

## Интерфейс

- 3 языка: EN / RU / 中文; 6 тем, 7 шрифтов

## Известные ограничения

- Forward secrecy (статические ключи чата) — в роадмапе
- Метаданные почты видны провайдерам (релей видит только хэш-адрес очереди)
- Вложения ограничены лимитами провайдера (25–30 МБ)

## Установка

```bash
# Linux — распаковать и запустить
tar xzf vault-desktop-0.1.157-linux-x86_64.tar.gz && ./vault-desktop

# Android — скачать APK с vault-msg.ru/releases

# CLI
cargo install --path vault-client
```
