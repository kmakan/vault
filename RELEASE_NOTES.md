# Vault v0.1.140 — Release Notes

**Дата**: 3 сентября 2026
**Платформы**: Linux (DEB, RPM, AppImage), Windows, Android (APK), CLI

## Что такое Vault

Приватный мессенджер, работающий через обычную почту. Без серверов.
Ключи и история — только на устройстве.

## Шифрование

- **Гибрид ML-KEM-768 + X25519** (PQ1) — постквантовый обмен ключами:
  HKDF-SHA256 из двух shared secret; компромат одного примитива не даёт ключ.
- **XChaCha20-Poly1305** — шифрование сообщений, вложений, локального хранилища.
- Legacy-путь X25519 для контактов без PQ-ключей (плавная миграция).
- Обмен ключами: QR-код, отпечаток (fingerprint) для верификации.

## Мессенджер

- 1-на-1 и групповые чаты (роли: создатель/админ/участник)
- Инвайты по QR/ссылке; membership по fingerprint — участник, сменивший
  почту, не выпадает из группы
- Редактирование, «удалить у меня», закрепление, реакции, ответы
- Избранное, исчезающие сообщения (TTL), архив/mute чатов
- Read receipts, статусы доставки
- Вложения (файлы/изображения), аудиосообщения, экспорт чатов
- Поиск (FTS5), папки чатов, заметки «для себя»
- Мультиаккаунтность; смена почты без потери ключей и контактов

## Звонки

- Голосовые 1-на-1: Opus 48 кГц, пофреймовое AEAD + DTLS-SRTP
- P2P через WebRTC, сигнализация — теми же E2E-конвертами по почте
- Мгновенный hangup по control DataChannel
- Рингтоны (выбор в настройках), нативные кнопки ответа в уведомлении,
  биометрическая разблокировка (Android)

## Безопасность

- Duress-пароль (пустое хранилище) / panic-код (полное стирание)
- SOS-рассылка с геолокацией
- Стелс: письма неотличимы от обычных (пустые темы, нет маркеров)
- Android: allowBackup=false, облачные бэкапы исключены
- Никакой телеметрии и сторонних SDK в сетевом пути

## Клиенты

- **Desktop** — Tauri 2 (Rust + Vue 3): Linux, Windows, macOS
- **Android** — Tauri 2, APK (universal, подписан release-ключом)
- **CLI** — Rust REPL, паритет wire-формата с desktop

## Интерфейс

- 3 языка: EN / RU / 中文
- 6 тем, 7 шрифтов

## Известные ограничения

- Нет forward secrecy (статические ключи чата) — в роадмапе
- Метаданные почты видны провайдерам (адреса, время)
- Доставка 30–60 с (IMAP IDLE — ~1 с); relay/push — в планах
- Вложения ограничены лимитами почтового провайдера (25–30 МБ)

## Установка

```bash
# Linux
sudo dpkg -i vault_0.1.140_amd64.deb   # или rpm / AppImage

# Android — скачать APK с vault-msg.ru

# CLI
cargo install --path vault-client
```
